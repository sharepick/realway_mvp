# Realway Workspace

印尼达人运营和 SMB 商户招商的 WhatsApp 网页演示。界面为简体中文，模拟会话与回复草稿使用印尼语或英语。应用使用 HTML、CSS 和 JavaScript，无需安装项目依赖。

## 启动

在解压后的 `realway-mvp` 目录打开终端，运行以下命令，然后浏览 [工作台](http://127.0.0.1:8080/)。

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

可以双击打开 `dist/index.html` 快速查看。使用本地服务器可获得稳定的浏览器存储行为。核心流程无需网络，在线时加载 Inter 字体。

## 演示流程

1. 保持管理员身份，在统一收件箱打开 Nadira Putri。点击 **分析对话** 查看兴趣、到店时间提议和原文依据。再点击 **AI 回复建议**，编辑印尼语草稿并点击 **模拟发送**。
2. 在右侧将达人阶段推进到 **已确认到店**，新建交稿跟进，或在跟进页完成现有任务。到期时间按雅加达时间录入和显示。
3. 在客户管理新建一个商户，填入城市、标签和沟通语言。打开会话后可维护商户阶段和记录模拟回复。
4. 在会话资料中更换负责人，在团队权限页查看交接记录。切换到 Ayu 和 Rafi，对照交接后的联系人、消息和任务可见范围。
5. 切回管理员看未读、待跟进、逾期、使用 AI 草稿发送的消息数和两类客户阶段分布。在员工工作报表切换 **日报** 与 **周报**，按雅加达日期查看发送消息、联系客户、阶段推进、完成跟进和当前逾期。期间工作量归属操作人，当前逾期归属现负责人。刷新后模拟业务记录仍可查看。浏览器站点数据清除后会重新加载初始演示记录。

## 源码

- `dist/index.html` 页面结构
- `dist/style.css` 桌面和窄屏样式
- `dist/app.js` 演示数据、收件箱、CRM、跟进、角色、规则草稿和看板
- `dist/conversation-analysis.js` 按规则从整段对话提取关注点、合作意向和到店安排
- `dist/team-report.js` 雅加达日期区间和员工工作量统计

四个身份均供演示切换，管理员与印尼主管在单一工作区享有相同权限。浏览器存储保留模拟业务记录，各浏览器独立。新版操作记录员工身份。旧记录没有身份时单独列出。权限只在前端模拟，草稿使用本地规则，当前状态为 WhatsApp 未连接。真实收发、员工登录、服务端权限、跨设备同步和模型调用属于后续接入。产品方案另附。

## 员工与联系人维护

管理员或主管可在团队权限页新增员工姓名、邮箱和岗位，保存后出现在演示身份、分配列表及工作报表中。新增员工目前是浏览器本地记录，正式邀请与登录待后端接入。客户管理支持含国家区号的 WhatsApp 号码、负责人和号码去重。已有演示联系人号码为空，可编辑补齐。首次联系仅模拟发送，接通 API 后须执行客户同意和获批模板校验。
